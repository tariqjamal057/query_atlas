🧪 LLM Archive Extension Test

Testing Instructions:

1. Load this extension in Chrome (chrome://extensions/)
2. Navigate to ChatGPT, Claude, Gemini, or DeepSeek
3. Start a conversation or enter some text
4. Click the LLM Archive extension icon
5. Click "Auto-Capture Current Page"
6. Check if data is captured properly

🔧 Debug Console

Open browser DevTools (F12) → Console tab to see debug logs when testing the extension.

Expected logs when auto-capture works:

  • ✅ "LLM Archive content script loaded on: [domain]"
  • ✅ "Content script received message: autoCapture"
  • ✅ "Starting autoCapture..."
  • ✅ "Platform config: [object]"
  • ✅ "Extracted data: {query, shareUrl, description, platformName}"

🚨 Common Issues & Solutions

Issue: "Could not communicate with page"

Solution: Refresh the page and try again

Issue: "No query found on page"

Solution: Make sure you've entered text or started a conversation

Issue: "Platform not supported"

Solution: Only works on ChatGPT, Claude, Gemini, and DeepSeek

📝 Extension Popup Features

  • Auto-Capture: Automatically extracts query and URL from supported platforms
  • Manual Entry: Fill out the form manually if auto-capture doesn't work
  • Platform Detection: Automatically detects which platform you're on
  • Statistics: Shows captured count and session count

✨ Test with Local Server

Make sure your LLM Archive web application is running on:

http://localhost:5000

The extension will submit captured data to this endpoint.
